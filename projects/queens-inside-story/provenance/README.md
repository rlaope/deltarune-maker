# Original game assets

The runtime expects prepared Nintendo DS and DELTARUNE assets under `bis/` and `dr/`. Set `QUEEN_ASSET_DIR` to the private asset directory or place a local `assets/` link beside the game. [Runtime inventory](runtime-assets.json) lists every required path and SHA-256. The source repository includes credit and extraction metadata. The local game build uses the actual media files supplied separately.

- **DELTARUNE** by Toby Fox and the DELTARUNE team supplies the Chapter 2 mansion, characters, portraits, font, dialogue sounds and other crossover effects. [DELTARUNE source inventory](deltarune.json) · [Official site](https://deltarune.com/)
- **Mario & Luigi: Bowser’s Inside Story** by AlphaDream and Nintendo supplies the DS command art, items, field and battle sounds, and Yoko Shimomura’s music. The boss finish uses the native Scutlet effect separated from recorded original gameplay. Its alpha is inferred from the original frames. [Nintendo DS visual inventory](bowser-ds.json) · [Field audio extraction](field-audio.md) · [Nintendo’s DS game page](https://www.nintendo.com/en-gb/Games/Nintendo-DS/Mario-Luigi-Bowser-s-Inside-Story-271584.html)

The original art and sounds belong to their respective rights holders. Use the asset handling rules in the [studio instructions](../../../AGENTS.md).
